# Pizza portion notes and note shortcuts

Each portion (mitad, tercio, cuarto) of a built pizza can carry its own note, written on the builder's last step; admins manage note shortcuts that the waiter taps instead of typing.
Branch: feat/pizza-portion-notes, one PR to main reviewed commit by commit. Migrations 20261201120000 and 20261202120000 applied to production (grants and RLS checked there).

## Specs

- S1: User: "podemos agregar notas a cada miyad tercio o cuarto que se avreue en armar pizza". Choice: "En el último paso, junto a la nota (Recomendado)" — "Antes de 'Agregar pizza' aparece una nota por porción. No rompe el avance automático y se escribe todo junto." Preview: "Mitad 1 · Hawaiana [ nota… ] / Mitad 2 · Peperoni [ nota… ] / Nota de la pizza [ … ] / [ − 1 + ] [ Agregar pizza ]". Only pizzas with 2+ portions show portion notes; an entera pizza keeps only "Nota de la pizza". Each portion row is labelled with its portion title and chosen style. Auto-advance (odd/tasks/pizza-builder-autoadvance.md) is unchanged.
- S2: Storage: a portion note is an optional field of the portion inside the pizza config (like `chiles`). The server (validate_pizza) trims it, drops it when blank, and rejects one longer than 80 characters with a clear Spanish message; older stored pizzas without notes stay valid. The note does not change the price.
- S3: Kitchen and Entrega show each portion's note under that portion (e.g. "½ Hawaiana — sin piña en la orilla"), in the same note style as the existing line notes; the order/receipt description of the pizza includes it where portions are described.
- S4: Más vendidas (popular_picks) and the fixed quick pizzas ignore portion notes when grouping and never return them, like the whole-pizza note today. A quick pizza tile adds the pizza without notes.
- S5: Choice for the note format: "Atajos + texto libre" with "(custom) agregar los atajos en admin" — admins manage a list of note shortcuts (e.g. "Bien cocida", "Sin cebolla") in Admin > Pizzas: add, remove, reorder. Free text stays. Tapping a shortcut in the builder appends it to that note ("Sin cebolla, bien cocida"); tapping it again removes it. Shortcuts appear for each portion note and for "Nota de la pizza".
- S6: Waiter devices (device secret) and signed-in admin/cashier read the shortcuts; only admins write them. Failing to load shortcuts never blocks the builder (notes stay free text).
- S7: User: "antes dime tambien hay atajos en ala hora de agregar notas en nota del pedido" + choice "Lista aparte en Admin (Recomendado)" — "Atajos de pedido como 'Pagan con $500', 'Entregar rápido' o 'Cubiertos'. Los de pizza ('Bien cocida', 'Sin cebolla') no tienen sentido para el pedido entero." Order note shortcuts are a separate admin-managed list (same rules as S5: add, remove, reorder, cap, label limit), shown as chips under "Nota del pedido (opcional)" in Revisar and under the "Nota del pedido" field of the open-order note modal; tap appends with ", ", tap again removes, free text stays, respecting MAX_ORDER_NOTES_LENGTH. Same read rules as S6. Admin manages it on the same Admin > Pizzas page in its own section ("Atajos de nota del pedido"); the pizza list section is titled "Atajos de notas de pizza".
- S8: User: "necesito que sean sutiles los atajos" + choice "Contorno fino, ámbar al tocar (Recomendado)" — "Pequeños (32 px), solo borde gris; al tocarlos se ponen ámbar suave como las notas." Applies to every note shortcut chip (portion notes, pizza note, order note), with dark-mode variants; ingredient/extra chips keep their current look.
